# H3-HexParser

Easily parse and map in Uber's H3 grid, just upload a file

Full deployment will be available soon. Current if you pip install the ```requirements.txt``` you can visualize the site sing uvicorn. CSV files are the only current accepted file, through Parquet and GeoParquet formats will be added shortly.
